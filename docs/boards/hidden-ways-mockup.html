C · Food diary pill My pick

A full-width white hairline pill above Supplements | Water: the apple in teal, Food diary, today's 1,240 kcal in grey and a chevron pointing right. It is built like the Saved days and Saved meals pills, which open their own screens the same way. It reads clearly as something to tap without using the ink pill, and adds 64px above Finlay's note; with nothing logged it shows just Food diary and the chevron.

A · Chevron on every opener My pick

Every row that opens gets its chevron, which turns down when the row opens, and the opened row shows Edit and Delete in words as it does today. This is a one-line change that follows the existing rule (a row that opens gets a chevron). A past event without a note stays bare.

B · Edit in words on the row

Each event you can change shows Edit in words at the right of its when-line, and it fades with its row. Tapping Edit goes straight to the Edit event sheet, which already has Delete event at its foot. A row with a note still folds open with its chevron. The cost is one more word on every upcoming row.

Each event you can change gets a ⋯ after the face. It opens a small menu right beside it with Edit and Delete, and Delete asks in the menu (Delete event?), the same way a chat message's menu does. This puts a third mark on every row and a menu the itinerary doesn't have yet.
